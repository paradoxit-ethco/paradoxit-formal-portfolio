# Paradoxit Formal Portfolio

A modern, formal, light-themed software developer portfolio website for Paradoxit.

## Run locally

This is a dependency-free static site. From the project directory, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Customize

- Update the editable profile fields, skills, projects, social URLs, and contact email in `index.html`.
- Replace the `hello@example.com` mailto destination in `script.js` with the preferred inbox.
- Adjust the light palette and responsive layout in `styles.css`.
- The full original product brief is available in [PORTFOLIO_BRIEF.txt](./PORTFOLIO_BRIEF.txt).

## Included

- Responsive navigation with mobile menu
- Hero, About, Skills, GitHub-backed Projects, Contact, and Footer sections
- Keyboard-friendly skip link and labeled form controls
- Reduced visual clutter, responsive layouts, hover states, and smooth scrolling
- Client-side contact validation with prepared email fallback
- Public repositories are displayed as project cards; private repositories are intentionally excluded.
